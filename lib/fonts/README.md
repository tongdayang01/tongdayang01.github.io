# 字体说明

由于 Google Fonts 在中国大陆可能无法访问，本网站已使用系统字体栈作为替代：

- 标题/导航：`'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', 'SimHei', sans-serif`
- 正文：`'Noto Serif SC', 'STSong', 'Songti SC', 'SimSun', serif`

## 可选增强

如需使用 Noto Sans/Serif SC 字体以获得最佳视觉效果，可通过以下方式：

1. 从 jsdelivr 镜像加载（推荐）：
   ```html
   <link href="https://cdn.jsdelivr.net/npm/@fontsource/noto-sans-sc@5.0.18/index.min.css" rel="stylesheet">
   ```

2. 或下载字体文件至此目录并在 HTML 中使用 @font-face 声明
